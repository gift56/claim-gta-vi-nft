## 5. wagmi config — `src/lib/wagmi.ts`

```ts
import { createConfig, http } from "wagmi";
import { sepolia } from "wagmi/chains";
import { coinbaseWallet, injected, walletConnect } from "wagmi/connectors";

const rpcUrl = process.env.NEXT_PUBLIC_SEPOLIA_RPC_URL;
const wcProjectId = process.env.NEXT_PUBLIC_WALLET_CONNECT_PROJECT_ID;

export const config = createConfig({
  chains: [sepolia],
  connectors: [
    injected(),
    walletConnect({ projectId: wcProjectId ?? "", showQrModal: true }),
    coinbaseWallet(),
  ],
  transports: { [sepolia.id]: rpcUrl ? http(rpcUrl) : http() },
});
```

- Sepolia **only** (chainId `11155111`, matching `CHAIN_ID` in `contractInfo.ts`).
- If the WalletConnect project id is missing, the connector list degrades to injected + coinbase at runtime — no crash.

## 8. Mint hook — `src/hooks/use-mint-character.ts`

Uses `useWriteContract`, `useWaitForTransactionReceipt`, `useAccount`, `useChainId`, `useSwitchChain` and imports `CONTRACT_ADDRESS`, `CONTRACT_ABI`, `CHAIN_ID` from `@/constants/contractInfo`.

Exported state machine (`type MintStatus = "idle" | "confirming" | "pending" | "success" | "error"`), derived from:

- `useAccount` → not connected ⇒ `idle` (button shows **Connect wallet to mint**)
- `useWriteContract` `isPending` ⇒ **confirming** (wallet approval open)
- `useWaitForTransactionReceipt({ hash })` `isPending` ⇒ **pending** (mining)
- receipt `status === "success"` ⇒ **success**; receipt or write error ⇒ **error** (`error.shortMessage ?? error.message` surfaced)

`mint(characterId: number)` calls `writeContract` with `address: CONTRACT_ADDRESS`, `abi: CONTRACT_ABI`, `functionName: "mintCharacter"`, `args: [BigInt(characterId)]`, `value: parseEther("0.05")` — price hardcoded here only because contract reads are out of scope; `// TODO(prompt 006): read mintPrice()` marks it.

Wrong network: if `useChainId() !== CHAIN_ID`, hook exposes `needsSwitch` and the button triggers `switchChainAsync({ chainId: CHAIN_ID })` before writing.
